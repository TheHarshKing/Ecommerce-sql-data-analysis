# Ecommerce-sql-data-analysis

## 📌 Project Overview

This project focuses on analyzing an e-commerce dataset using **SQL and MySQL** to extract useful business insights related to products, orders, payments, referrals, revenue, and cancelled orders.

## 🎯 Objectives

* Analyze product-wise sales
* Analyze order status
* Analyze payment methods
* Analyze referral sources
* Calculate average unit price
* Calculate total revenue
* Calculate total quantity sold
* Calculate cancelled order value

## 🛠️ Tools & Technologies

* **MySQL**
* **MySQL Workbench**
* **SQL**

## 📊 Analysis Performed

### 1. Product Analysis

Find the total price for each product.

### 2. Order Status Analysis

Find the total price for each order status.

### 3. Payment Method Analysis

Find the total price for each payment method.

### 4. Referral Source Analysis

Find the total price for each referral source.

### 5. Average Order Value

Calculate the average unit price.

### 6. Total Revenue

Calculate the total revenue generated.

### 7. Total Quantity

Calculate the total quantity of products sold.

### 8. Cancelled Order Value

Calculate the total value of cancelled orders.
